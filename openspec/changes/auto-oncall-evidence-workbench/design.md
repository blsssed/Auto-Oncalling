# 设计
显式范围覆盖告警字段。时间默认告警前后 15 分钟或最近 30 分钟；任务范围作为不可放宽的过滤条件。最多修订 3 次计划、6 次 CLS 查询，保存原因与差异。

报告提供 version=1 的结构化 diagnosis，与旧 Markdown 并存。引用校验当前 owner/task 证据及真实摘录；无有效证据时降为 insufficient_evidence。引用有效不代表因果结论已独立验证。

案例保存要求 confirmed=true、非空根因与建议。新增复核字段，旧案例 pending；知识检索在向量和 BM25 融合前排除未复核诊断案例。索引沿用持久任务。

Vite 仅注入白名单 API 地址并阻止私有 JSON 访问。/demo 不初始化认证或业务 API，只加载脱敏录制；没有录制时显示空状态。
